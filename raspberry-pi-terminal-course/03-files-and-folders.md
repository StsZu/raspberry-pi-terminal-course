# Урок 3 — Файли і папки

## Про що цей урок

Файлова система Linux — дерево папок. Проєкт на Pi — це папка з файлами: Python-скрипти, конфіги, логи. Цей урок — створення структури проєкту, перегляд і редагування файлів.

**Головна мета — не вивчити всі команди Linux, а навчитися швидко знаходити потрібну команду, розуміти її ризик і застосовувати її в реальному сценарії на Raspberry Pi.**

---

## Команди

### `pwd`

| | |
|---|---|
| **Що робить** | Поточна папка |
| **Коли** | Перед `cd`, `cp`, `rm` — знати де ти |
| **Приклад** | `pwd` → `/home/stanislav` |
| **Ризик** | **Низький** |

---

### `ls` / `ls -la`

| | |
|---|---|
| **Що робить** | Список файлів; `-l` деталі, `-a` приховані (включно з `.`) |
| **Коли** | Подивитися вміст папки |
| **Приклад** | `ls -la` |
| **Результат** | `-rw-r--r-- 1 stanislav stanislav 42 Jun 30 10:00 main.py` |
| **Ризик** | **Низький** |

---

### `cd` / `cd ..` / `cd ~`

| | |
|---|---|
| **Що робить** | Перехід у папку; `..` — батьківська; `~` — домашня |
| **Коли** | Навігація по проєкту |
| **Приклад** | `cd ~/projects/led-test` |
| **Помилки** | `No such file or directory` — папки немає |
| **Ризик** | **Низький** |

---

### `mkdir`

| | |
|---|---|
| **Що робить** | Створює папку |
| **Коли** | Нова структура проєкту |
| **Приклад** | `mkdir -p ~/projects/led-test` (`-p` — вкладені папки) |
| **Ризик** | **Низький** |

---

### `touch`

| | |
|---|---|
| **Що робить** | Створює порожній файл або оновлює час модифікації |
| **Коли** | Швидко створити файл перед редагуванням |
| **Приклад** | `touch main.py` |
| **Ризик** | **Низький** |

---

### `nano`

| | |
|---|---|
| **Що робить** | Текстовий редактор у Terminal |
| **Коли** | Редагувати конфіги, скрипти на Pi без GUI |
| **Приклад** | `nano main.py` |
| **Керування** | `Ctrl+O` зберегти, `Ctrl+X` вийти |
| **Ризик** | **Низький** |

**Приклад вмісту в nano:**

```python
print("Hello from Raspberry Pi 5")
```

---

### `cat` / `less` / `head` / `tail`

| | |
|---|---|
| **Що робить** | `cat` — весь файл; `less` — посторінково; `head`/`tail` — початок/кінець |
| **Коли** | Перегляд без редагування |
| **Приклад** | `cat main.py`, `tail -f app.log` (лог у реальному часі) |
| **Ризик** | **Низький** |

---

### `cp` / `mv`

| | |
|---|---|
| **Що робить** | `cp` — копія; `mv` — перемістити або перейменувати |
| **Коли** | Бекап, організація файлів |
| **Приклад** | `cp main.py main.py.bak`, `mv old.py new.py` |
| **Помилки** | `cp` без `-r` для папки — помилка |
| **Ризик** | **Низький** (перезаписує файли без попередження в деяких випадках) |

---

### `rm` / `rmdir`

| | |
|---|---|
| **Що робить** | Видалення файлу / порожньої папки |
| **Коли** | Прибрати зайве |
| **Приклад** | `rm file.txt`, `rmdir empty-dir` |
| **Ризик** | **Середній** (`rm` безповоротний, без кошика) |

---

## rm vs rm -r vs rm -rf — обов'язково знати

```bash
rm file.txt          # видаляє ОДИН файл
rm -r folder         # видаляє папку і весь вміст (рекурсивно)
rm -rf folder        # те саме, БЕЗ запитів підтвердження (-f = force)
```

| Команда | Що видаляє | Ризик |
|---------|------------|-------|
| `rm file.txt` | Один файл | Середній |
| `rm -r folder` | Папка з усім всередині | Високий |
| `rm -rf folder` | Папка миттєво, без питань | **ВИСОКИЙ** |

**Ніколи не запускай `rm -rf` без перевірки шляху.** Помилка `rm -rf ~/ projects` (пробіл) може знищити домашню папку.

Перед видаленням: `pwd`, `ls -la`, переконайся в шляху.

---

## Сценарій: створити проєкт LED-test

```bash
mkdir ~/projects
cd ~/projects
mkdir led-test
cd led-test
touch main.py
nano main.py
```

У nano введи:

```python
# LED test project
print("GPIO project ready")
```

Збережи (`Ctrl+O`, Enter), вийди (`Ctrl+X`):

```bash
cat main.py
ls -la
cd ~
pwd
```

## Практичне завдання

1. Створи `~/projects/my-first-pi-project` з файлом `README.txt`.
2. У `nano` напиши один рядок опису проєкту. Перевір через `cat`.
3. Скопіюй файл: `cp README.txt README.bak`. Перейменуй оригінал: `mv README.txt info.txt`.
4. Створи папку `tmp`, потім видали її: `rmdir tmp` (порожню).
5. **Контроль:** поясни вголос різницю між `rm`, `rm -r`, `rm -rf`.

# Урок 2 — Основи Linux Terminal

## Про що цей урок

Terminal — текстовий інтерфейс до операційної системи. Ти вводиш **команду**, shell її виконує і повертає результат. На Raspberry Pi це той самий принцип, що на Mac, але шляхи файлів, пакети і деякі утиліти відрізняються.

**Базові поняття:**

- **Terminal** — вікно, куди вводиш команди
- **Shell** — програма-інтерпретатор (на Pi зазвичай `bash`)
- **Prompt** — рядок на кшталт `stanislav@raspberrypi:~ $` — чекає на команду
- **Command** — ім'я програми (`ls`, `cd`, `python3`)
- **Argument** — параметр команди (`ls /home`)
- **Option / flag** — модифікатор (`ls -la`, `-l` і `-a` — опції)
- **$PATH** — список папок, де shell шукає виконувані файли

**Відмінність Pi від Mac:** на Pi — Linux (Debian/Raspberry Pi OS), домашня папка `/home/user`, пакети через `apt`, GPIO і `vcgencmd` — тільки на Pi.

**Головна мета — не вивчити всі команди Linux, а навчитися швидко знаходити потрібну команду, розуміти її ризик і застосовувати її в реальному сценарії на Raspberry Pi.**

## Команди

### `echo $SHELL`

| | |
|---|---|
| **Що робить** | Показує, який shell використовується |
| **Коли** | Діагностика середовища |
| **Приклад** | `echo $SHELL` |
| **Результат** | `/bin/bash` |
| **Помилки** | — |
| **Ризик** | **Низький** |

---

### `whoami` / `hostname` / `pwd`

| | |
|---|---|
| **Що робить** | User, ім'я машини, поточна папка |
| **Коли** | Орієнтація після SSH |
| **Приклад** | `whoami && hostname && pwd` |
| **Результат** | Три рядки з інформацією |
| **Ризик** | **Низький** |

---

### `clear`

| | |
|---|---|
| **Що робить** | Очищає екран Terminal |
| **Коли** | Коли забагато тексту на екрані |
| **Приклад** | `clear` |
| **Ризик** | **Низький** |

---

### `history`

| | |
|---|---|
| **Що робить** | Показує історію введених команд |
| **Коли** | Знайти команду, яку вже вводив |
| **Приклад** | `history` або `history | tail -20` |
| **Ризик** | **Низький** |

### `which <command>`

| | |
|---|---|
| **Що робить** | Показує повний шлях до виконуваного файлу |
| **Коли** | Дізнатися, звідки запускається програма |
| **Приклад** | `which python3` |
| **Результат** | `/usr/bin/python3` |
| **Помилки** | Порожній вивід — команда не знайдена в PATH |
| **Ризик** | **Низький** |

---

### `command -v <command>`

| | |
|---|---|
| **Що робить** | Аналог `which`, працює і для shell builtin |
| **Коли** | Скрипти, перевірка наявності команди |
| **Приклад** | `command -v git` |
| **Результат** | `/usr/bin/git` |
| **Ризик** | **Низький** |

---

### `echo $PATH`

| | |
|---|---|
| **Що робить** | Показує змінну PATH (папки пошуку програм) |
| **Коли** | Команда «не знайдена», хоча программа встановлена |
| **Приклад** | `echo $PATH` |
| **Результат** | `/usr/local/bin:/usr/bin:/bin:...` |
| **Ризик** | **Низький** |

---

### `echo $PATH | tr ':' '\n'`

| | |
|---|---|
| **Що робить** | PATH по одному шляху на рядок — зручніше читати |
| **Коли** | Розібратися в структурі PATH |
| **Приклад** | `echo $PATH | tr ':' '\n'` |
| **Ризик** | **Низький** |

---

### `man <command>`

| | |
|---|---|
| **Що робить** | Відкриває manual (довідку) по команді |
| **Коли** | Потрібні всі опції і опис |
| **Приклад** | `man ls` |
| **Вихід** | `q` — вийти з man |
| **Помилки** | `No manual entry` — немає man-сторінки |
| **Ризик** | **Низький** |

---

### `apropos <keyword>`

| | |
|---|---|
| **Що робить** | Шукає команди за ключовим словом у описах man |
| **Коли** | Не пам'ятаєш точну назву команди |
| **Приклад** | `apropos network` |
| **Результат** | Список команд з коротким описом |
| **Ризик** | **Низький** |

---

## Практичне завдання

1. Підключись по SSH. Виконай `echo $SHELL`, `whoami`, `pwd`.
2. `which python3` і `command -v git` — запиши шляхи.
3. `echo $PATH | tr ':' '\n'` — скільки папок у PATH?
4. `man ls` — прочитай опис, вийди через `q`.
5. `apropos copy` — знайди команди для копіювання файлів.

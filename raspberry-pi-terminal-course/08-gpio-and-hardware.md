# Урок 8 — GPIO і залізо

## Про що цей урок

GPIO (General Purpose Input/Output) — контакти на Raspberry Pi для керування LED, датчиками, реле. Це **не «просто дротик»** — неправильне підключення може **пошкодити Raspberry Pi**.

**Ключові правила:**

- Логіка GPIO — **3.3V**, не 5V. Подача 5V на GPIO — ризик згоріти.
- GPIO не розраховані на великі струми (LED — через резистор; мотори/реле — через транзистор, драйвер, модуль реле).
- Завжди перевіряй схему перед підключенням.
- Спочатку — `pinout` і документація, потім — дроти.

```text
GPIO — це не "просто дротик". Неправильне підключення може пошкодити Raspberry Pi.
```

**Головна мета — не вивчити всі команди Linux, а навчитися швидко знаходити потрібну команду, розуміти її ризик і застосовувати її в реальному сценарії на Raspberry Pi.**

## Команди

### `pinout`

| | |
|---|---|
| **Що робить** | ASCII-схема розводки GPIO Raspberry Pi |
| **Коли** | Перед будь-яким підключенням — знайти правильний пін |
| **Приклад** | `pinout` |
| **Результат** | Діаграма з номерами фізичних пінів і BCM-номерами |
| **Ризик** | **Низький** |

---

### `ls /dev/gpiochip*`

| | |
|---|---|
| **Що робить** | Список GPIO-чіпів у системі |
| **Приклад** | `ls /dev/gpiochip*` → `/dev/gpiochip0` ... |
| **Ризик** | **Низький** |

---

### `gpiodetect`

| | |
|---|---|
| **Що робить** | Показує доступні GPIO chips (бібліотека libgpiod) |
| **Приклад** | `gpiodetect` |
| **Результат** | `gpiochip0 [pinctrl-rp1] (54 lines)` |
| **Помилки** | `command not found` — встанови gpiod |
| **Ризик** | **Низький** |

---

### `gpioinfo`

| | |
|---|---|
| **Що робить** | Детальний стан ліній GPIO (використання, напрям) |
| **Приклад** | `gpioinfo` |
| **Ризик** | **Низький** |

---

### `gpioset` / `gpioget`

| | |
|---|---|
| **Що робить** | Встановити / прочитати значення GPIO лінії |
| **Коли** | Тест без Python, низькорівневе керування |
| **Приклад** | `gpioset gpiochip0 17=1` (обережно — лише з правильною схемою!) |
| **Ризик** | **Високий** без розуміння схеми |

---

## Встановлення gpiod

Якщо `gpioinfo` або `gpioset` недоступні:

```bash
sudo apt update
sudo apt install gpiod
```

Перевір:

```bash
pinout
gpiodetect
gpioinfo
ls /dev/gpiochip*
```

## 3.3V vs 5V

| | GPIO Pi | Arduino (для порівняння) |
|---|---------|-------------------------|
| Логіка | 3.3V | 5V |
| Макс. струм на пін | ~16 mA (рекомендовано менше) | вище |

Датчики 5V — через level shifter. Реле — модуль з оптоізоляцією, живлення реле окремо від GPIO.

## Практичне завдання (без підключення заліза)

1. `pinout` — знайди GPIO17 (BCM) на схемі. Запиши фізичний номер піна.
2. `sudo apt install gpiod` (якщо потрібно).
3. `gpiodetect` і `gpioinfo` — скільки ліній на chip0?
4. `ls /dev/gpiochip*` — перелічи чіпи.
5. **Не підключай** LED/реле, поки не маєш схему з резистором/модулем.

# Урок 4 — Пакети і оновлення

## Про що цей урок

Raspberry Pi OS базується на Debian. Пакети (програми, бібліотеки) встановлюються через **apt** з **репозиторіїв** — офіційних дзеркал пакетів. Перед установкою завжди оновлюй список пакетів (`update`), інакше apt може не знайти нові версії.

**Ключові поняття:**

- **apt** — менеджер пакетів Debian/Raspberry Pi OS
- **package** — іменований набір файлів (наприклад `git`, `python3-pip`)
- **repository** — сервер зі списком і файлами пакетів
- **update** — оновити *список* доступних версій (не встановлює нові версії)
- **upgrade** — встановити нові версії вже встановлених пакетів

**sudo** — виконати команду від імені root (адміністратора). Потрібен пароль. Без sudo `apt install` не спрацює.

**Головна мета — не вивчити всі команди Linux, а навчитися швидко знаходити потрібну команду, розуміти її ризик і застосовувати її в реальному сценарії на Raspberry Pi.**

---

## Команди

### `sudo apt update`

| | |
|---|---|
| **Що робить** | Завантажує актуальні списки пакетів з репозиторіїв |
| **Коли** | Перед `install`, `upgrade`; раз на тиждень-місяць |
| **Приклад** | `sudo apt update` |
| **Результат** | `Reading package lists... Done` |
| **Помилки** | `Could not resolve` — немає інтернету; `Failed to fetch` — проблема з репозиторієм |
| **Ризик** | **Низький** |

---

### `sudo apt upgrade`

| | |
|---|---|
| **Що робить** | Оновлює встановлені пакети до нових версій з репозиторію |
| **Коли** | Після `update`, для безпеки і стабільності |
| **Приклад** | `sudo apt upgrade` |
| **Результат** | Список пакетів, запит підтвердження `Y/n` |
| **Ризик** | **Середній** (рідко ламає залежності; на продакшн — обережно) |

---

### `sudo apt full-upgrade`

| | |
|---|---|
| **Що робить** | Агресивніше оновлення — може видаляти/замінювати залежності |
| **Коли** | Великий перехід версії ОС |
| **Ризик** | **Середній** |

---

### `sudo apt install <package>`

| | |
|---|---|
| **Що робить** | Встановлює пакет і залежності |
| **Коли** | Потрібна нова програма |
| **Приклад** | `sudo apt install git`, `sudo apt install python3-pip` |
| **Результат** | `Setting up git ...` |
| **Помилки** | `Unable to locate package` — неправильна назва або треба `update` |
| **Ризик** | **Низький–середній** (встановлює софт з репозиторію) |

---

### `sudo apt remove <package>` / `sudo apt purge <package>`

| | |
|---|---|
| **Що робить** | `remove` — видаляє програму; `purge` — + конфіги |
| **Коли** | Прибрати непотрібний пакет |
| **Ризик** | **Середній** |

---

### `apt search <keyword>`

| | |
|---|---|
| **Що робить** | Шукає пакети за назвою/описом |
| **Коли** | Не знаєш точну назву пакета |
| **Приклад** | `apt search gpio` |
| **Ризик** | **Низький** (читання, без sudo) |

---

### `apt show <package>`

| | |
|---|---|
| **Що робить** | Детальна інформація про пакет |
| **Приклад** | `apt show git` |
| **Ризик** | **Низький** |

---

### `apt list --installed`

| | |
|---|---|
| **Що робить** | Список встановлених пакетів |
| **Приклад** | `apt list --installed | grep python` |
| **Ризик** | **Низький** |

---

## Типовий workflow оновлення

```bash
sudo apt update
sudo apt upgrade
```

Встановлення інструментів для проєкту:

```bash
sudo apt update
sudo apt install git
sudo apt install python3-pip
apt search gpio
apt show git
```

---

## Ризики sudo

- `sudo` дає повні права — помилка в команді може пошкодити систему
- Не копіюй команди з інтернету без розуміння
- Використовуй `sudo` тільки коли потрібно (apt, systemctl, файли в `/etc`)

---

## Практичне завдання

1. `sudo apt update` — переконайся, що без помилок.
2. `apt show git` — прочитай опис. Якщо git немає: `sudo apt install git`.
3. `sudo apt install python3-pip` (якщо ще не встановлено).
4. `apt search gpio` — знайди пакет `gpiod`.
5. `apt list --installed | grep git` — підтверди установку.

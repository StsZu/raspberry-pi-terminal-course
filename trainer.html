Raspberry Pi 5 Terminal Trainer

Практичний тренажер Linux-команд для Pi 5: SSH, apt, мережа, Python/venv, GPIO, systemd, логи, Git. Ти починаєш на Mac (%); після ssh команди виконуються на Pi ($), exit повертає на Mac. Емуляція без реального виконання. Команда зараховується лише в точному вигляді (або як явний еквівалент, напр. ls -al = ls -la). ↑/↓ — історія, Tab — автодоповнення команди зі списку.
